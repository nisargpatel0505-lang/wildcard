# Suit Kingdom Home Artwork

These four PNG files are the full-resolution image-generation sources for the
WILDCARD suit-kingdom home themes. They were generated specifically for this
project and visually reviewed before integration.

Runtime WebP derivatives live in `assets/art/backgrounds/`:

- `wildcard-theme-hearts-kingdom-home.webp`
- `wildcard-theme-spades-kingdom-home.webp`
- `wildcard-theme-diamonds-kingdom-home.webp`
- `wildcard-theme-clubs-kingdom-home.webp`

The runtime files are normalized to `1080 × 1920`, WebP quality 94. Source
artwork intentionally contains no WILDCARD logo, buttons, text, frame or
watermark; Flutter composes the real interface on top.
